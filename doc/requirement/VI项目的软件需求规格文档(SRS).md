# VI-软件需求规格文档

## 1. 引言

### 1.1 目的

本文档皆在明确VI系统的功能需求、性能需求、设计约束和其他相关需求。本文档旨在为开发者提供详细的需求说明，以确保系统的开发和实现符合用户的期望和业务目标。

本文档主要面向项目负责人、系统架构人员、开发人员、测试人员、运维人员作为项目实施过程中的需求基准文件。

### 1.2 项目背景

随着视频数据规模快速增长，传统人工查看视频的方式存在效率低、分析成本高等问题。为了提高视频内容理解能力，实现视频数据自动化分析，设计并开发
VideoIntelligence 视频智能分析平台。

### 1.3 项目目标

本系统致力于利用人工智能技术提升教学视频内容的理解和管理效率，通过对视频内容进行智能分析，将分散的知识内容转化为结构化、可视化的知识体系，帮助学习者提升自主学习效果，同时为教育工作者提供可视化教学内容分析和管理支持。

### 1.4 范围

系统名称：VI (VideoIntelligence)-基于大语言模型分析的多模态视频解析系统

主要功能：

- 用户可以本地或以链接的形式上传教学视频，支持多种视频格式。
- 对视频进行语音识别 (ASR)
- 对画面文字进行识别 (OCR)
- 对视频内容进行多模态分析，提取关键知识点和概念 (LLM)
- 生成知识点大纲、详细知识点、思维导图 (LLM)

边界说明：

本系统主要负责教学视频的上传、智能分析、知识点提取、知识体系构建以及可视化展示等核心业务功能。用户认证、消息通知等部分功能可通过第三方服务实现，系统仅负责与第三方平台进行接口对接，不负责第三方服务内部的数据处理和运行维护。

本系统不涉及视频采集设备的管理，不负责原始教学内容的生产，不提供硬件环境。

## 2. 系统概述

### 2.1 系统介绍

VideoIntelligence 是一个基于人工智能技术的视频智能分析平台，旨在通过计算机视觉、语音识别以及大语言模型等人工智能技术，对用户上传的视频数据进行自动化分析和内容理解。

系统采用前后端分离架构以及微服务架构设计，通过用户认证、视频管理、任务调度、AI分析等模块，实现视频资源管理、智能分析任务处理以及分析结果展示。

系统面向需要进行视频内容理解和智能处理的用户，提供便捷、高效的视频分析服务。

### 2.2 产品功能概述

系统主要包括用户认证、视频管理、智能分析、任务管理以及结果展示等功能模块。用户通过系统上传视频资源，并创建对应分析任务，系统调用人工智能模型完成视频内容分析，最终将分析结果返回用户查看。

### 2.3 用户特征

| 用户角色 | 描述           | 主要权限                         |
|----------|----------------|----------------------------------|
| 普通用户 | 系统主要使用者 | 注册登录、上传视频、查看分析结果 |
| 管理员   | 系统维护人员   | 用户管理、资源管理、系统配置     |

### 2.4 系统运行环境

| 类别         | 环境                      |
|--------------|---------------------------|
| 操作系统     | Linux / Windows           |
| 后端开发环境 | Java 21                   |
| 开发框架     | Spring Boot、Spring Cloud |
| 数据库       | MySQL                     |
| 缓存         | Redis                     |
| 对象存储     | MinIO / OSS               |
| 容器环境     | Docker                    |

### 2.5 设计约束

技术约束:

- 系统需使用 Java 21 及 Spring Boot、spring Cloud、FastAPI 框架进行开发。
- 系统采用微服务架构，各业务模块独立部署，通过接口进行通信。
- 系统需要依赖数据库、缓存以及对象存储服务。

业务约束:

- 用户只能访问自己拥有的视频资源。
- 视频分析任务需要用户登录后提交。
- 大规模视频处理任务需要采用异步方式执行。

外部约束:

- 系统部分人工智能能力依赖第三方AI服务接口。
